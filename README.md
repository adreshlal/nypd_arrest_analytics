# NYPD Arrest Analytics

This project is an exploratory and statistical analysis of arrest data from the New York Police Department (NYPD). It aims to uncover spatial and demographic trends in arrest patterns across different boroughs of New York City using regression models, visualizations, and clustering techniques.

## 📁 Dataset

The data used is sourced from the publicly available NYPD Arrest Data, spanning multiple years and containing detailed arrest records including borough, age, sex, race, offense type, and arrest date.

- **Dataset file**: [`NYPD_Arrest_Data__Year_to_Date__20241216.zip`](https://github.com/adreshlal/nypd_arrest_analytics/blob/main/NYPD_Arrest_Data__Year_to_Date__20241216.zip)

## 🛠️ Tools Used

- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn)
- Jupyter Notebook
- Git & GitHub

## 📈 Objectives

- Examine borough-wise disparities in arrest categories
- Analyze demographic influence on arrest patterns
- Predict crime categories using regression models
- Identify high-incidence clusters via spatial analysis

## 🔍 Insights Gained

- Borough and demographic factors correlate strongly with arrest categories
- Predictive models reveal patterns in felony vs misdemeanor classification
- Visualizations improve understanding of arrest dynamics across NYC
